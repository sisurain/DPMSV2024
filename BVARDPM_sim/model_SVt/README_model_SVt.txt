=========================================================================
README — model_SVt/
=========================================================================

This folder estimates the BVAR-t-CSV model (Chan, 2020) on the simulated
datasets generated by the gen_data/ folder.

Model specification:

  y_t = X_t * A + eps_t
  eps_t ~ N(0, lambda_t * exp(h_t) * Sigma)
  lambda_t ~ IG(nu/2, nu/2)         i.i.d. fat-tail scaling
  h_t = rho * h_{t-1} + eta_t       AR(1) common stochastic volatility
  Sigma ~ IW(S0, nu0)
  A ~ Minnesota prior (with intercept)
  nu ~ MH sampler with Newton-Raphson proposal

The model combines a persistent scalar log-volatility process h_t with
an i.i.d. Student-t outlier component lambda_t parameterised through
the degrees-of-freedom parameter nu.

=========================================================================
Execution
=========================================================================

  run_SVt_sim.m

    Input:  ../sim_data/simdata_DGP{d}_T{T}_R20.mat  (6 files)
    Output: results/SVt_DGP{d}_T{T}_rep{rr}.mat      (120 files)

  Run from within the model_SVt/ directory. The script loops over
  all 3 DGPs, 2 sample sizes, and 20 replications.

=========================================================================
File list
=========================================================================

  run_SVt_sim.m
    Main estimation script. Implements the full MCMC sampler: draws
    VAR coefficients A and covariance Sigma jointly, samples scalar
    log-volatility h_t via acceptance-rejection Metropolis-Hastings,
    draws lambda_t from its IG full conditional, updates degrees of
    freedom nu via MH, and draws SV persistence rho and innovation
    variance sigh2.

--- Utility files from Chan (2020) codebase ---

The following files are from the replication code of:

  Chan, J.C.C. (2020). Large Bayesian VARs: A flexible Kronecker
  error covariance structure. Journal of Business and Economic
  Statistics, 38(1), 68-79.

  sample_h.m
    Samples the common stochastic volatility h_t using an acceptance-
    rejection Metropolis-Hastings algorithm with a Gaussian proposal
    constructed via Newton-Raphson (IWLS).

  sample_nu.m
    Samples the degrees-of-freedom parameter nu using a Metropolis-
    Hastings step with a Gaussian proposal centred at the Newton-
    Raphson mode of the full conditional.

=========================================================================
Output format
=========================================================================

Each results .mat file contains:

  lam_hat    T x 1   posterior mean of lambda_t (variance scale)
  h_hat      T x 1   posterior mean of h_t (mean-centred)
  lam_true   T x 1   true lambda_t from DGP
  h_true     T x 1   true h_t from DGP (mean-centred)
  nu_hat     scalar  posterior mean of degrees of freedom
  rho_hat    scalar  posterior mean of SV persistence rho
  sigh2_hat  scalar  posterior mean of SV innovation variance
  dgp, T_sim, r      bookkeeping scalars
