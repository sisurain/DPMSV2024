=========================================================================
README — model_DPMCSV/
=========================================================================

This folder estimates the DPM-CSV (Dirichlet Process Mixture with Common
Stochastic Volatility) model on the simulated datasets generated by the
gen_data/ folder.

Model specification:

  y_t = X_t * A + eps_t
  eps_t ~ N(mu_t,  lambda_t * exp(h_t) * Sigma)
  (mu_t, lambda_t) | z_t ~ DPM
  h_t = rho * h_{t-1} + eta_t,  eta_t ~ N(0, sigh2)

The DPM component assigns each observation to a cluster via latent
indicators z_t, where each cluster has its own mean mu_k and variance
scale lambda_k drawn from a Normal-Inverse-Gamma base measure. The
common scalar stochastic volatility h_t follows an AR(1) process.
Since the DPM provides time-varying intercepts mu_t, no intercept
is included in the regressor matrix X.

=========================================================================
Execution
=========================================================================

  run_DPMCSV_sim.m

    Input:  ../sim_data/simdata_DGP{d}_T{T}_R20.mat  (6 files)
    Output: results/DPMCSV_DGP{d}_T{T}_rep{rr}.mat   (120 files)

  Run from within the model_DPMCSV/ directory. The script loops over
  all 3 DGPs, 2 sample sizes, and 20 replications.

=========================================================================
File list
=========================================================================

  run_DPMCSV_sim.m
    Main estimation script. Implements the full MCMC sampler: draws
    VAR coefficients A and covariance Sigma jointly, samples scalar
    log-volatility h_t via acceptance-rejection Metropolis-Hastings,
    updates DPM cluster assignments via collapsed Gibbs, samples
    cluster parameters (lambda_k, mu_k) from their NIG posteriors,
    and draws SV persistence rho and innovation variance sigh2.

  construct_prior_A_func.m
    Constructs the Minnesota prior for the VAR slope coefficients.
    Returns the prior mean A0, prior variances VA0, and OLS-based
    scaling factors sig2.

  nigSV.m
    Handle class implementing the Normal-Inverse-Gamma (NIG)
    sufficient statistics used as the DPM base measure. Supports
    sequential addSample/delSample operations for the collapsed
    Gibbs sampler and computes the log predictive density via a
    multivariate Student-t distribution.

  oneDPM.m
    One-pass collapsed Gibbs sampler for initialising the DPM
    cluster assignments. Scans observations in random order,
    assigning each to an existing cluster or creating a new one
    based on the predictive probabilities.

  sample_h.m
    Samples the common scalar stochastic volatility h_t using an
    acceptance-rejection Metropolis-Hastings algorithm with a
    Gaussian proposal constructed via Newton-Raphson (IWLS).

  randmn.m
    Draws from a categorical distribution using inverse transform
    sampling. Used by the DPM collapsed Gibbs sweep.

=========================================================================
Output format
=========================================================================

Each results .mat file contains:

  lam_hat    T x 1   posterior mean of lambda_t
  h_hat      T x 1   posterior mean of h_t (mean-centred)
  mu_hat     T x n   posterior mean of mu_t
  lam_true   T x 1   true lambda_t from DGP
  h_true     T x 1   true h_t from DGP (mean-centred)
  K_hat      scalar  posterior mean number of clusters
  alpha_hat  scalar  posterior mean DPM concentration parameter
  rho_hat    scalar  posterior mean of SV persistence rho
  sigh2_hat  scalar  posterior mean of SV innovation variance
  dgp, T_sim, r      bookkeeping scalars
