=========================================================================
README — model_SVo/
=========================================================================

This folder estimates the SVo (BVAR with common outlier scaling) model
on the simulated datasets generated by the gen_data/ folder.

Model specification (Carriero, Clark, Marcellino & Mertens, 2022):

  y_t = PAI(L) * y_{t-1} + v_t
  v_t = inv(A) * diag(sqrt(h_{1,t}), ..., sqrt(h_{N,t})) * o_t * e_t
  e_t ~ N(0, I)
  o_t in {1, 2, ..., 20}  (common outlier scale, Beta-Bernoulli prior)
  h_{j,t} follows correlated random-walk SV (KSC mixture sampler)

The outlier scale o_t is a common scalar that inflates volatility at
discrete time points. The lambda_t equivalent for comparison with the
DPM-CSV model is o_t^2 (variance scale).

=========================================================================
Execution
=========================================================================

  run_SVo_sim.m

    Input:  ../sim_data/simdata_DGP{d}_T{T}_R20.mat  (6 files)
    Output: results/SVo_DGP{d}_T{T}_rep{rr}.mat      (120 files)

  Run from within the model_SVo/ directory. The script loops over
  all 3 DGPs, 2 sample sizes, and 20 replications.

=========================================================================
File list
=========================================================================

  run_SVo_sim.m
    Main estimation script. Calls mcmcVARSVobar for each replication,
    extracts posterior means of the outlier scale (lambda_t = o_t^2)
    and common log-volatility (cross-sectional average of per-variable
    log-variances after stripping the outlier scale), and saves results.

--- Utility files from CCMM (2022) codebase ---

The following files are from the replication code of Carriero, Clark,
Marcellino and Mertens (2022). They are required by the SVo Gibbs
sampler and should not be modified.

  mcmcVARSVobar.m             SVo Gibbs sampler
  CTA.m                       Triangular algorithm for VAR coefficients
  obarGibbsdraw.m             Common outlier scale sampler
  StochVolKSCcorrsqrt.m       KSC stochastic volatility sampler
  KSC.m                       KSC mixture smoother
  getKSC7values.m             KSC 7-component mixture constants
  rwnoisePrecisionBasedSampler.m   Precision-based state sampler
  betadraw.m                  Beta distribution draws
  checkdiff.m                 Numerical comparison utility
  parid.m                     Parallel worker ID
  progressbar.m               Progress display
  vec.m                       Vectorise utility

=========================================================================
Output format
=========================================================================

Each results .mat file contains:

  lam_hat    T x 1   posterior mean of lambda_t (o_t^2, variance scale)
  h_hat      T x 1   posterior mean of common h_t (mean-centred)
  lam_true   T x 1   true lambda_t from DGP
  h_true     T x 1   true h_t from DGP (mean-centred)
  dgp, T_sim, r      bookkeeping scalars
