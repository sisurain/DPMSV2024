=========================================================================
README — BVARDPM_fullsample/
=========================================================================

This folder contains the full-sample estimation of the DPM-OIMSV model
on the CCMM 16-variable monthly dataset: the Dirichlet process mixture
innovation specification combined with the order-invariant multivariate
stochastic volatility structure of Chan, Koop and Yu (2024).

=========================================================================
Folder structure
=========================================================================

  BVARDPM_fullsample/
    README.txt                    this file
    STEP0_prepare_CCMM_data.m     data preparation (run first)
    RUN_fullsample.m              master runner (estimation + analysis)
    post_analysis.m               post-estimation summaries and Figure 1
    202601MD.csv                  raw FRED-MD vintage (January 2026)
    CCMM16_data.mat               generated by STEP0
    DPM_OIMSV/
      BVAR_DPM_OIMSV_FE.m         main estimation script
      post_tail_balance_DPM_OIMSV.m   tail-balance diagnostic (Figure 2)
      (supporting files; see subfolder README)
      results_DPM_OIMSV.mat       generated (not included)

=========================================================================
Workflow
=========================================================================

Option A — run everything via the master script:

  RUN_fullsample.m (from this folder). Prepares the data if needed,
  copies it into the model subfolder, runs the estimation, and calls
  post_analysis.m.

Option B — run the steps individually:

  1.  STEP0_prepare_CCMM_data.m
        Input:   202601MD.csv
        Output:  CCMM16_data.mat
        (copy CCMM16_data.mat into DPM_OIMSV/)

  2.  DPM_OIMSV/BVAR_DPM_OIMSV_FE.m    (run from within DPM_OIMSV/)
        Output:  DPM_OIMSV/results_DPM_OIMSV.mat
        10,000 posterior draws after 5,000 burn-in.

  3.  post_analysis.m (from this folder)
        Loads the results file and produces: posterior summaries and
        convergence diagnostics; Excel exports of the posterior means
        of lambda_t and h_{i,t}; the plot of the posterior mean of
        lambda_t with its pointwise 90% credible band; and the
        posterior statistics of the DPM concentration parameter and
        the number of active clusters.

  4.  DPM_OIMSV/post_tail_balance_DPM_OIMSV.m
        (run from within DPM_OIMSV/)
        Computes the tail-balance diagnostic and produces the
        tail-asymmetry bar chart and summary table.

=========================================================================
Data
=========================================================================

The 16 CCMM variables from the FRED-MD dataset (January 2026 vintage),
with CCMM-style transformations, estimated with p = 12 lags on the
sample 1959:Mar through 2025:Sep.

=========================================================================
Files not included
=========================================================================

The results file (results_DPM_OIMSV.mat) is not included because of
its size (over 1 GB). It is fully reproducible by running the workflow
above. The generated data file CCMM16_data.mat and the figure, table,
and Excel outputs of the analysis scripts are likewise reproduced by
the scripts.
