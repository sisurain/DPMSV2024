=========================================================================
README — BVARDPM_connectedness/
=========================================================================

This folder contains the bank-network connectedness application: the
generalized forecast error variance decomposition (GFEVD) connectedness
of Diebold and Yilmaz (2014) computed under the DPM-OISV model and
under a Gaussian stochastic volatility benchmark, for a panel of 30
global banks' daily range-based volatilities.

The SV benchmark is a structural mirror of the DPM-OISV specification:
the same order-invariant contemporaneous matrix B0 (sampled row by row
via the Waggoner-Zha-Villani step), the same per-variable AR(1)
log-volatilities and samplers, and the same inline GFEVD computation,
with the Dirichlet process mixture removed (lambda_t = 1, mu_t = 0)
and a global intercept included in each equation (the DPM cluster
means absorb the location in DPM-OISV, so the intercept ensures a
symmetric comparison). Any difference between the two connectedness
paths is therefore attributable to the DPM error distribution alone.

    results/                      populated by the estimation scripts
    dy_figures/                   populated by the plot script

=========================================================================
Workflow
=========================================================================

  1.  load_ddly_data.m
        Input:   data/ddly-data.csv
        Output:  data/ddly_top30_data.mat
        Selects the 30 largest banks by assets and constructs the
        daily log-variance series.

  2.  BVAR_DPM_OIMSV_FE_DY.m
        Input:   data/ddly_top30_data.mat
        Output:  results/results_DPM_OIMSV_DY.mat
        DPM-OISV estimation with p = 3 lags; 10,000 posterior draws
        after 5,000 burn-in, heavy storage thinned by a factor of 10.
        The GFEVD (horizon H = 10) and the connectedness measures are
        computed inline for each retained draw on a subsampled date
        grid, so no posterior draws need to be revisited afterwards.

  3.  run_SV_fullsample_DY.m
        Input:   data/ddly_top30_data.mat
        Output:  results/results_SV_DY.mat
        The structural-mirror SV benchmark, same settings.

      Steps 2 and 3 are independent and can be run in separate MATLAB
      sessions.

  4.  extract_DY_summary.m (run from this folder)
        Loads both results files and produces the cross-model summary:
        total connectedness statistics and dynamic ranges by episode,
        the total connectedness comparison at the five crisis dates,
        and the averaged GFEVD snapshot matrices. Writes dy_summary.mat.

  5.  make_connectedness_plots_DY.m (run from this folder)
        Plots the posterior median of total connectedness with 16th-
        84th percentile credible bands for both models over 2007-2014,
        and exports the plotted series to CSV. Output in dy_figures/.

=========================================================================
Data
=========================================================================

The daily bank realized-volatility panel (ddly-data.csv) is from
Demirer, Diebold, Liu and Yilmaz (2018), "Estimating Global Bank
Network Connectedness", Journal of Applied Econometrics, 33(1), 1-15,
obtained from the paper's public data repository
(financialconnectedness.org). The file is included here with
attribution for replication purposes.

load_ddly_data.m retains the 30 largest banks by assets. The
estimation sample runs from 2003-09-17 through 2014-02-07 with p = 3
lags (the standard Diebold-Yilmaz daily lag length).

=========================================================================
File list
=========================================================================

  load_ddly_data.m
    Reads the raw panel, selects the top-30 banks, constructs the
    log-variance series, and saves the estimation dataset.

  BVAR_DPM_OIMSV_FE_DY.m
    DPM-OISV estimation adapted from the full-sample sampler
    (BVAR_DPM_OIMSV_FE.m), with the GFEVD-based connectedness
    summaries computed inline during the MCMC.

  run_SV_fullsample_DY.m
    Gaussian SV benchmark: the DPM-OISV sampler with the Dirichlet
    process mixture removed and a global intercept added.

  compute_GFEVD.m
    Generalized forecast error variance decomposition of Pesaran and
    Shin (1998) with row normalization following Diebold and Yilmaz,
    plus the total and directional connectedness measures.

  extract_DY_summary.m
    Cross-model summary extraction (see workflow step 4).

  make_connectedness_plots_DY.m
    Total connectedness figure (see workflow step 5).

--- Supporting files ---

  nigMSV.m
    Normal-inverse-gamma sufficient statistics class for the DPM base
    measure under the time-varying covariance.

  oneDPM_MSV.m
    One-pass collapsed Gibbs initialisation for the DPM.

  randmn.m
    Categorical distribution sampler.

  sample_SV_OISV.m
    KSC mixture sampler for the individual log-volatilities. Adapted
    from the Chan, Koop and Yu (2024) replication code.

  sample_SV0para_OISV.m
    Sampler for the SV persistence and innovation-variance parameters.
    Adapted from the Chan, Koop and Yu (2024) replication code.

  get_C_OISV_FE.m
    Scaling matrix for the Minnesota-type horseshoe prior.

  get_resid_var_OISV_FE.m
    AR(4) residual variances used to scale the Minnesota prior.

=========================================================================
Files not included
=========================================================================

The results files (contents of results/), the generated figures
(contents of dy_figures/), the prepared dataset ddly_top30_data.mat,
and the summary file dy_summary.mat are not included because of their
size. All are fully reproducible by running the workflow above.
