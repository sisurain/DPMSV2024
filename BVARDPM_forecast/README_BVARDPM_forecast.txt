=========================================================================
README — BVARDPM_forecast/
=========================================================================

This folder contains the 42-variable pseudo out-of-sample forecasting
exercise. Five models are estimated and compared: SVo and SVO
(Carriero, Clark, Marcellino & Mertens, 2024), SV-t (Chan, 2020), and
the two proposed semiparametric specifications, DPM-CSV and DPM-OISV.
DPM-OISV is the reference model in all ratio tables: it appears in the
numerator, so values below 1 favor DPM-OISV.

=========================================================================
Folder structure
=========================================================================

  BVARDPM_forecast/
    README.txt                      this file
    STEP0_prepare_forecast_data.m   data preparation (run first)
    postprocess_forecast_results.m  tables and PIT figures
    make_spaghetti_plots.m          forecast-path figures
    data/
      2026-01-MD.csv                raw FRED-MD vintage (January 2026)
      FREDMD42_forecast_data.mat    generated by STEP0
    model_SVo/                      SVo forecasting
    model_SVO/                      SVO forecasting
    model_SVt/                      BVAR-t-CSV forecasting
    model_DPMCSV/                   DPM-CSV forecasting
    model_DPMOISV/                  DPM-OISV forecasting
    results/                        per-origin results (populated by runners)
    tables_figures/                 tables and plots (populated by postprocess)
    spaghetti_figures/              forecast-path plots (populated by
                                    make_spaghetti_plots.m)

Each model subfolder contains its own README describing its files.

=========================================================================
Workflow
=========================================================================

Step 1 — Prepare the data:

  STEP0_prepare_forecast_data.m
    Input:   data/2026-01-MD.csv
    Output:  data/FREDMD42_forecast_data.mat

Step 2 — Run each model's forecasting script (from within its folder):

  model_SVo/run_SVo_forecast.m        -> results/results_SV_o_forecast.mat
  model_SVO/run_SVO_forecast.m        -> results/results_SVO_forecast.mat
  model_SVt/run_SVt_forecast.m        -> results/results_SVt_forecast.mat
  model_DPMCSV/run_DPMCSV_forecast.m  -> results/results_DPMCSV_forecast.mat
  model_DPMOISV/run_DPMOISV_forecast.m -> results/results_DPMOISV_forecast.mat

  Design: expanding window with a fixed initial sample. First forecast
  origin 2004:Dec, last origin 2025:Sep (250 origins). At each origin
  the model is re-estimated on the available data and forecasts are
  produced for horizons h = 1, ..., 12 months ahead. Each runner stores
  per-origin summaries (predictive means, realized values, CRPS,
  marginal log scores, one-step-ahead joint log score, predictive
  quantiles, and PIT values); full predictive draws are processed
  inside the loop and discarded.

  The five runners are independent of each other and can be executed
  in separate MATLAB sessions or on separate cluster nodes.

Step 3 — Produce tables and calibration figures:

  postprocess_forecast_results.m (run from this folder). Loads all five
  results files and produces:

    RMSE and CRPS ratio tables by regime with DM-West significance
    stars (Newey-West HAC standard errors)
    Joint log predictive score table (per-origin averages by regime)
    PIT histograms at h = 1
    LaTeX table exports in tables_figures/

Step 4 — Produce the forecast-path figures:

  make_spaghetti_plots.m (run from this folder). Loads the SVo, SV-t,
  and DPM-OISV results and, for each forecast origin, plots the full
  h = 1, ..., 12 predictive path against the realized series. Two views
  are produced per variable: the full evaluation sample and a
  COVID-period zoom (file suffix _covid). The forecast-path figures in
  the paper are the COVID-zoom versions for PCE inflation and the
  unemployment rate. Output in spaghetti_figures/.

=========================================================================
Data
=========================================================================

42 monthly variables from the FRED-MD dataset (January 2026 vintage),
spanning output and income, labor markets, housing, orders and
inventories, money and credit, interest rates, spreads, prices, stock
markets, and exchange rates. All 16 variables from the CCMM (2024)
16-variable set are included.

Transformations follow the CCMM convention: annualised log growth
rates (1200 * dlog) for growth-rate variables, log levels for housing
variables, and levels for rates, spreads, and utilization series.
Usable sample: 1962:Jul through 2025:Sep, with p = 12 lags.

Excluded from the 42: ACOGNO (raw data begin in 1992) and UMCSENTx
(interior missing values in the early sample).

=========================================================================
Evaluation design
=========================================================================

  Evaluation regimes:
    Pre-COVID:   origins up to 2020:Feb
    COVID:       2020:Mar to 2021:Dec
    Post-COVID:  2022:Jan onward
    Full sample: all 250 origins

  Reported horizons: h = 1, 6, 12.

  Point forecasts:    RMSE ratios (DPM-OISV in numerator)
  Density forecasts:  CRPS ratios (DPM-OISV in numerator)
  Multivariate:       one-step-ahead joint log predictive scores
  Calibration:        PIT histograms at h = 1
  Significance:       Diebold-Mariano-West tests with Newey-West HAC
                      standard errors (*** p<0.001, ** p<0.01, * p<0.05)

=========================================================================
Files not included
=========================================================================

The per-origin results files (contents of results/) and the generated
tables and figures (contents of tables_figures/ and spaghetti_figures/)
are not included in this package because of their size. All are fully
reproducible by running the workflow above. The generated data file
FREDMD42_forecast_data.mat is likewise reproduced by STEP0.
